## 조사 기준

- 4성급 이상 또는 그에 준하는 관리 수준
- 성인 3인이 **각자 방을 쓸 수 있는** 침실 2~3개 구성
- 1주~1개월 장기 체류 가능 여부
- 93세 고령자 관점: 계단 · 응급 의료 접근성 · 취사 · 세탁

## 한계

- 가격은 **공개 요금 기준 참고가**이며 9월 28일자 실시간 견적이 아닙니다.
- 장기(1주·1개월) 요금은 공개하는 곳이 없어 전부 직접 협의 대상입니다.
- 사진은 직접 삽입하지 못하고, 숙소별로 사진이 있는 실제 페이지 3곳 링크로 대체했습니다.
- 지도 좌표는 공개 주소 기준 근사 위치(블록 단위)입니다.
- 모든 외부 링크는 도메인 생존(DNS) 확인을 거쳤습니다.
